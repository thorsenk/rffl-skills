# RFFL Skills

Public, versioned AI skill bundles for the RFFL.

## Available skills

### `rffl-owners-draft-strategy`

Builds, updates, versions, and renders RFFL-branded fantasy football draft cheat sheets.

- [Skill instructions](rffl-owners-draft-strategy/SKILL.md)
- [Installation and usage](rffl-owners-draft-strategy/README.md)
- Current bundle version: `0.1.0`

## Install

Copy the complete skill folder into a project:

```text
<project>/.claude/skills/rffl-owners-draft-strategy/
```

Or install it for all projects:

```text
~/.claude/skills/rffl-owners-draft-strategy/
```

See the skill README for dependencies, commands, validation, and rendering instructions.
