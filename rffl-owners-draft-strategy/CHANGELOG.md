# Changelog

## 0.1.1 - 2026-08-28

- Replaced form-style intake with a one-question conversation.
- Removed redundant season, draft-date, and mode questions when context supplies them.
- Prioritized league settings, scoring, lineup, availability, and draft position over output details.
- Added regression prompts for draft-week intake behavior.

## 0.1.0 - 2026-08-26

- Created the first testable skill bundle.
- Added adaptive fantasy-football intake and research guidance.
- Added scoring, keeper, Superflex, salary-cap, and IDP branches.
- Added canonical JSON schema and deterministic PDF renderer.
- Added dynamic positional and overall boards with continuation pages.
- Added explicit tier logic, locks, update workflow, semantic versioning, and smoke tests.
- Included the RFFL general tiered template as a visual reference.
